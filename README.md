# Controle Financeiro Pessoal (Flutter)

App offline-first para controle de receitas e despesas, usando Hive.

## Funcionalidades
- Resumo mensal (receitas, despesas, saldo)
- Cadastro de transacoes (receita/despesa, categoria, valor, data, observacao)
- Listagem com filtro e exclusao por deslize
- Relatorio de despesas por categoria

## Como rodar

```bash
flutter pub get
flutter run
```
